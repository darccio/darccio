<section class="h-item">

<h2 class="p-name">Mergo</h2>

<p class="p-summary">A Go library for merging structs and maps of the same type, filling fields that have zero values. The project is stable and frozen: it does not accept new features.</p>

- Import path: `dario.cat/mergo`.
- <a class="u-url" href="/mergo/">Usage guide</a> and [API documentation](https://pkg.go.dev/dario.cat/mergo).
- <a href="https://github.com/darccio/mergo">Code and issues<span class="visually-hidden">: Mergo</span></a>.

</section>

<section class="h-item">

<h2 class="p-name">Zas</h2>

<p class="p-summary">A static site generator written in Go. It uses Markdown, HTML and a template, with a simple file structure. This site is built with Zas.</p>

- Module: `github.com/darccio/zas`.
- <a class="u-url" href="/zas/">Documentation</a> and <a href="https://pkg.go.dev/github.com/darccio/zas">Go API<span class="visually-hidden">: Zas</span></a>.
- <a href="https://github.com/darccio/zas">Code and issues<span class="visually-hidden">: Zas</span></a>.

</section>

<section class="h-item">

<h2 class="p-name">darna</h2>

<p class="p-summary">An atomic commit validator for Go. It checks that staged files form a complete change and do not depend on code left out of the commit.</p>

- Module: `dario.cat/darna`.
- <a class="u-url" href="/darna/">Documentation and installation</a> and <a href="https://pkg.go.dev/dario.cat/darna">Go API<span class="visually-hidden">: darna</span></a>.
- <a href="https://github.com/darccio/darna">Code and issues<span class="visually-hidden">: darna</span></a>.

</section>
