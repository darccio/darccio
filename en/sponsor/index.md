<h1 class="p-name">Support</h1>

If my [open-source projects](/en/projects/) are useful to you, you can [support my work through GitHub Sponsors](https://github.com/sponsors/darccio).

The GitHub page lists the available sponsorship options. Mergo is the main project I feature there, alongside other open-source projects.

The public [funding.json](/funding.json) file lists funding channels in a machine-readable format. To discuss a direct contribution, you can write to me through [Contact](/en/contact/).
