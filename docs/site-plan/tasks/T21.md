# T21 Generate Markdown twins in Zas

Opt-in markdown_output writes post-template pre-Markdown content beside HTML for .md pages, publish:false exclusions, no unexecuted actions or private config leakage, preserve embeds cleanly where possible. Avoid collision with source/deploy reaper and standalone contact.md -> contact.md same URL. Existing HTML pages need conversion or separate policy.

**Repository:** zas. **Phase:** Agents. **Depends on:** T05.

**Status:** Planned. **Subagent:** /root/t21_markdown (task review completed; implementation is tracked separately).

## Repository findings

- generate.go currently converts Markdown before render executes text/template. Capturing render's processed buffer produces HTML, not post-template Markdown. Add an opt-in Markdown preparation stage, execute page actions once, and feed its result to both conversion and twin emission.
- Current claims cover only stale sources and one HTML destination; sourceIsNewer checks HTML only. Reaper preserves stale publish:false outputs and has no twin lifecycle.

## Acceptance

- Write only within deploy: section/index.md -> section/index.md beside index.html; contact.md -> contact.md beside contact.html. Preserve HTML URLs and source bytes; reject deploy overlap and output collisions before writes, including unchanged sources.
- Strip leading private YAML configuration; emit only body plus explicitly allowlisted public metadata. Never serialize Page, Directory, or Extra. Execute normal Go actions once; document template:false literals and reject unresolved executable actions.
- Resolve built-in Markdown/plain/HTML embeds into complete readable content with containment/depth guards; if faithful emission is unsupported, fail explicitly and permit page-level twin opt-out. Never publish unresolved embeds/plugins or execute plugins twice.
- Suppress twins for publish:false and explicitly excluded drafts; retain the existing live Delete Facebook #3 URL. HTML sources remain unsupported and documented. Track both output files, removal and toggle state; disabled default preserves existing behavior.

## Verification

- Run go test ./... and go test -race ./.... Fixtures compare disabled output bytes with baseline.
- Exercise full/incremental builds, missing twins, source deletion/rename, publish:false transitions, opt-out transitions, uppercase extensions, collisions, and deploy/source overlap rejection.
- Assert rendered template values, preserved Markdown fences, no configuration sentinel or source mutation, and clean nested supported embeds.
