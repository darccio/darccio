## Independent migration verification

Fresh temporary modules ran with Go 1.26. The direct case starts at `github.com/imdario/mergo v0.3.16`, checks default merging, rewrites its import, runs `go get dario.cat/mergo@v1.0.2` and `go mod tidy`, and verifies only the vanity module remains and tests pass.

The indirect case includes a local dependency requiring the legacy path at v1.0.0 and a direct vanity dependency at v1.0.2. Its first `go mod tidy` reproduces the module-path mismatch. Adding `replace github.com/imdario/mergo => github.com/imdario/mergo v0.3.16` allows tidy and tests to pass with both import paths. This is temporary compatibility advice; the long-term fix is upgrading the dependency's imports.
