## Trust and formats

Fetches read only size-bounded, selected regular Git blobs from reviewed repositories and verify the full immutable SHA. No checkout, fetched configuration, build script, layout or code runs. Symlinks/submodules, unsafe paths, duplicate sources/routes, missing files, local links outside the selected set and mismatched source/repository license copies fail assembly.

`-no-plugins` alone does not stop templates or built-in embeds. The compiler first renders fetched Markdown as literal data with Goldmark's raw HTML disabled, then supplies a trusted `template: false` HTML wrapper to the usual `zas -full -no-plugins` build. Literal Go examples survive without executing; fetched raw HTML cannot introduce active embeds or scripts. Navigation is generated from the reviewed manifest rather than evaluated from a fetched embed file.

HTML links point to canonical trailing-slash documentation pages. Markdown preserves portable source-relative links: `/zas/configuration/` declares `/zas/configuration.md`, while landings declare `/mergo/index.md`, `/zas/index.md` and `/darna/index.md`. Compiler-owned mappings are the only exception to ordinary index-twin guessing and unrendered-template rejection. Personal pages retain their existing conventions. Full project context identifies each section's source Markdown URL; original project licenses remain exact and are reflected in the footer.
